# Lookup: Page Inventory by Module

**Public Module**:
- Checkout page (`/checkout`) - Order checkout with delivery and payment
- Saved Items page (`/saved-items`) - Wishlist display

**User Profile Module**:
- User Profile page (`/profile`) - Profile with tabs (overview, personal info, security)

**Shop Module**:
- Shop Dashboard (`/shop`) - Shop overview with stats
- Product Management (`/shop/products`) - Add/edit products
- Shop Create (`/shop/create`) - Create new shop
- Shop Settings (`/shop/settings`) - Manage shop, listings, staff, analytics

**Admin Module**:
- Admin Dashboard (`/admin`) - Admin overview with stats, charts, tables
- Settings page (`/admin/settings`) - Admin settings (categories, users, moderation)
- User Management (`/admin/users`) - User management table
- Moderation page (`/admin/moderation`) - Content moderation queue

**Shared Components**:
- Listing Card - Reusable product card
- Sidebar - Main navigation sidebar
- Avatar, Badge, Alert, Tabs, Skeleton, EmptyState - UI components
