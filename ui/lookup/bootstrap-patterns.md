# Lookup: Bootstrap Usage Patterns

**Most Common Classes**:

**Cards**:
- `card`, `card-header`, `card-body`, `card-footer`, `shadow-sm`, `h-100`

**Buttons**:
- `btn`, `btn-primary`, `btn-secondary`, `btn-outline-*`, `btn-sm`, `btn-lg`

**Forms**:
- `form-control`, `form-select`, `form-label`, `form-text`, `form-check`, `is-invalid`, `valid-feedback`, `invalid-feedback`

**Layout**:
- `container`, `row`, `col-*`, `d-flex`, `flex-column`, `gap-*`, `mb-*`, `py-*`, `text-center`

**Typography**:
- `text-muted`, `text-primary`, `text-success`, `text-danger`, `text-white`, `text-gray-*`

**Tables**:
- `table`, `table-hover`, `table-striped`, `table-light`, `table-dark`, `table-responsive`

**Badges**:
- `badge bg-*` (primary, success, warning, danger, secondary, info), `text-bg-*`

**Alerts**:
- `alert alert-*` (success, danger, info, warning)

**Loading**:
- `spinner-border`, `spinner-border-sm`, `visually-hidden`

**Icons**:
- FontAwesome classes (`fas fa-*`, `fab fa-*`), `me-2`, `ms-2` for spacing

**Navigation**:
- `nav`, `nav-pills`, `nav-link`, `nav-item`, `active`

**Reference**: Bootstrap 5.3.8 documentation
