# Guide: Migration Priority

**Purpose**: Phased approach to migrating UI components to shadcn-style.

**Phase 1: Foundation**
1. ✅ Add CSS variables (tokens.css)
2. ✅ Create semantic color utilities
3. ✅ Implement Badge component
4. ✅ Standardize form fields

**Phase 2: Core Components**
5. ✅ Create Avatar component
6. ✅ Implement Tabs component
7. ✅ Add Alert component
8. ✅ Create Skeleton loader

**Phase 3: Page Updates**
9. ✅ Update User Profile (complex tabs)
10. ✅ Update Admin Dashboard (stats cards)
11. ✅ Update Product Management (forms)
12. ✅ Update Listing Card (reusable component)

**Phase 4: Advanced Features** (Future)
13. Implement Toast notifications
14. Add Dialog components
15. Create DataTable component
16. Implement Pagination component

**Key Points**:
- Foundation must be complete before Phase 2
- Core components should be reusable
- Page updates use core components
- Advanced features can be added incrementally

**Reference**: See `UI_RULES.md` for detailed guidelines
